
# Chess

This real-time chess game allows players to compete instantly with live move updates and smooth gameplay. It offers an interactive and responsive interface where two players can join a match, make moves in real time, and enjoy a seamless online chess experience. The game focuses on accuracy, speed, and a clean user experience for both casual and competitive players.
# ChessBoard

![App Screenshot](https://i.postimg.cc/QC0YVBZg/Screenshot-2025-11-23-232238.png)



## Features

- Real-Time Gameplay: Instant move updates with no delays.
- Online Matchmaking: Play against other players instantly.
- Clean Chessboard UI: Smooth, modern, and easy-to-use interface.
- Valid Move Highlighting: Shows allowed moves for each piece.
- Move History: Track all previous moves during the match.
## Tech Stack

**Client:** React

**Server:** Node, Express, Websockets

**Database:** MongoDb
